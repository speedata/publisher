# `Tablehead`


Gibt den Tabellenkopf an.

## Attribute


`page` (optional)
: Die Seite, auf der der Tabellenkopf erscheinen soll. Voreinstellung ist »alle«


  - `first`: Nur auf der ersten Seite.
  - `all`: Auf allen Seiten. Falls »first« definiert, erscheint der Tabellenkopf auf allen Seiten bis auf der ersten.



## Bemerkungen

Der Inhalt von Tabellenkopf wird auf jeder Seite einer automatisch umbrochenen Tabelle wiederholt.
