# `Case`


Stellt einen Fall einer Fallunterscheidung ([`Switch`]({{% relref "switch" %}})) dar. Der erste Fall, der zutrifft, wird ausgeführt. Weitere Fälle werden nicht betrachtet. Wird kein Fall erfüllt, dann wird, falls vorhanden, das Element [`Otherwise`]({{% relref "otherwise" %}}) ausgeführt.
