# `Margin`


Enthält die Angaben über den Seitenrand des zu druckbaren Bereich.



## Kindelemente

(keine)

## Elternelemente

<a href="../pagetype"><code>Pagetype</code></a>

## Attribute


`bottom` (Längenangabe)
: Rand unten



`inner` (Längenangabe, optional, _seit Version 4.19.29_)
: Rand innen



`left` (Längenangabe, optional)
: Rand links



`outer` (Längenangabe, optional, _seit Version 4.19.29_)
: Rand außen



`right` (Längenangabe, optional)
: Rand rechts



`top` (Längenangabe)
: Rand oben






## Beispiel


```xml
<Margin left="2cm" right="1cm" top="1cm" bottom="1cm" />
```
