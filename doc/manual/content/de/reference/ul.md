# `Ul`


Erzeugt eine Stichpunktliste mit Aufzählungspunkten



## Kindelemente

<a href="../forall"><code>ForAll</code></a>, <a href="../li"><code>Li</code></a>

## Elternelemente

<a href="../setvariable"><code>SetVariable</code></a>, <a href="../text"><code>Text</code></a>, <a href="../textblock"><code>Textblock</code></a>

## Attribute


`fontfamily` (Text, optional, _seit Version 4.3.1_)
: Name der Schriftfamilie. Voreinstellung ist »text« (mit kleinem t).






## Beispiel


```xml
<PlaceObject>
  <Textblock>
    <Ul>
      <Li><Value>Erster Eintrag</Value></Li>
      <Li><Value>Zweiter Eintrag</Value></Li>
      <Li><Value>Dritter Eintrag</Value></Li>
    </Ul>
  </Textblock>
</PlaceObject>

```
