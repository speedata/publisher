# `Pageformat`


Legt die Größe des Ausgabemediums (z.B. DIN A4) fest. Voreinstellung ist eine Breite von 210mm und eine Höhe von 297mm.

(keine)

## Attribute


`height` (Längenangabe)
: Höhe des Ausgabemediums.



`width` (Längenangabe)
: Breite des Ausgabemediums.
