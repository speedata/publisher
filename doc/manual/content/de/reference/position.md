# `Position`
_seit Version 2.3.26_

Ein Element zum aktuellen [`Overlay`]({{% relref "overlay" %}}) hinzufügen.

## Elternelemente

<a href="../overlay"><code>Overlay</code></a>

## Attribute


`x` (Zahl)
: Die horizontale Position (0=links, 100=rechts).



`y` (Zahl)
: Die vertikale Position (0=unten, 100=oben).
