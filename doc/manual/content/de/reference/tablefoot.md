# `Tablefoot`


Gibt den Tabellenfuß an.



## Kindelemente

<a href="../copy-of"><code>Copy-of</code></a>, <a href="../forall"><code>ForAll</code></a>, <a href="../switch"><code>Switch</code></a>, <a href="../tablerule"><code>Tablerule</code></a>, <a href="../tr"><code>Tr</code></a>, <a href="../value"><code>Value</code></a>

## Elternelemente

<a href="../function"><code>Function</code></a>, <a href="../table"><code>Table</code></a>

## Attribute


`page` (optional)
: Der Tabellenfuß wird nur auf den angegebenen Seiten platziert. Voreinstellung ist, dass er auf jeder Seite erscheint.


  - `all`: Tabellenfuß auf allen Seiten darstellen.
  - `last`: Den Tabellenfuß nur auf der letzten Seite anzeigen.



## Bemerkungen

Der Inhalt von Tabellenfuß wird auf jeder Seite einer automatisch umbrochenen Tabelle wiederholt.
