The speedata Publisher creates high-quality PDF documents from XML data — product catalogs, price lists, data sheets and much more.
This manual guides you from first steps to advanced topics and serves as a reference at the same time.

New here? Start with the [Hello World example]({{< relref "helloworld" >}}) — you'll create your first PDF in minutes.
