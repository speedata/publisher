## [Version 5](version-5/)

### 5.4

Massive speed improvements, more HTML/CSS support, letterspacing, more XPath functions, Section element, new VSCode extension, margin protrusion fix.

### 5.2

New XML parser, improved XPath functions, enhanced HTML/CSS rendering, better international and typographic support, PDF metadata improvements.

### 5.0

New default XML/XPath parser, HarfBuzz text shaper with bidirectional typesetting, PDF/UA accessibility support, speedata Pro package.

## [Version 4](version-4/)

### 4.20

Fully accessible documents, robust XPath parser, ZUGFeRD attachment enhancements, object mirroring, strict namespace handling, spot color saturation.

### 4.18

New defaults for XPath engine and font loader, new logging backend, automatic image resizing, Markdown support.

### 4.16

Complete overhaul of MetaPost integration, new optional XPath engine.

### 4.14

New filename syntax for images, outline fonts, table column minwidth, XPath matches() function, Pro package.

### 4.12

PDFOptions displaymode, delayed SetVariable execution, hyperlink border colors, SHA256/SHA512 functions, Clip command.

### 4.10

Bug fixes, runtime.execute() and xml.decode_xml() in Lua filter. Last stable version with LuaJIT/FFI.

### 4.8

Bug fixes, Tablerule color="-", VSpace with height and minheight attributes.

### 4.6

Enhanced REST API, NewPage deprecation, macOS 12 compatibility, color profile in distribution, Go-based XML parser.

### 4.4

Transparency for text and images, MetaPost integration, Windows 64-bit, document separation, logical page numbering, improved hyperlinks.

### 4.2

Better OpenType font support, basic print CSS, new paragraph builder, HarfBuzz font shaper, CJK and Arabic script support, bidirectional typesetting.

### 4.0

New paragraph builder, firstmark/lastmark functions, improved server mode, HTML mode, new English manual, external image conversion tools.
