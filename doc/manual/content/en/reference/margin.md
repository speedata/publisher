# `Margin`


Set the margin of the document or master page.



## Child elements

(none)

## Parent elements

<a href="../pagetype"><code>Pagetype</code></a>

## Attributes


`bottom` (length)
: Bottom margin



`inner` (length, optional, _since version 4.19.29_)
: Inner margin



`left` (length, optional)
: Left margin



`outer` (length, optional, _since version 4.19.29_)
: Outer margin



`right` (length, optional)
: Right margin



`top` (length)
: Top margin






## Example


```xml
<Margin left="2cm" right="1cm" top="1cm" bottom="1cm"/>
```
