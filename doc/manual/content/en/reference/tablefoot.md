# `Tablefoot`


Create a repeating table footer.



## Child elements

<a href="../copy-of"><code>Copy-of</code></a>, <a href="../forall"><code>ForAll</code></a>, <a href="../switch"><code>Switch</code></a>, <a href="../tablerule"><code>Tablerule</code></a>, <a href="../tr"><code>Tr</code></a>, <a href="../value"><code>Value</code></a>

## Parent elements

<a href="../function"><code>Function</code></a>, <a href="../table"><code>Table</code></a>

## Attributes


`page` (optional)
: This command is only valid for the given pages. The default is to place the foot on all pages.


  - `all`: Place the footer on all pages.
  - `last`: Display the table footer only on the last page.
